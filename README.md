# WebGlazer docs

User docs for WebGlazer, built with Mintlify and served at https://webglazer.com/docs.

Preview locally: `npx mint dev`. Writing rules: STYLE.md.

Design: `style.css` and `webglazer-hero.js` copy the webglazer.com FAQ page look (values from the landing-page repo). Light mode only. Mintlify's Assistant (a Pro feature) is turned off in the Mintlify dashboard; the free plan does not include it.
